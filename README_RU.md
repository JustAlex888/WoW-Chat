# WoW Chat

[English](README.md) | [Русский](README_RU.md)

Лёгкий аддон постоянной истории чата, копирования и резервирования настроек Blizzard Chat для **World of Warcraft: Legion 7.3.5**.

> Текущая стабильная версия: **v1.0.0**

## Возможности

- Постоянная история чата между игровыми сессиями
- Раздельное хранение истории по персонажам
- Окно копирования сохранённой истории
- Окно копирования открывается на самых новых сохранённых сообщениях
- Сохранение цветов сообщений в окне копирования
- Режим **«Чистый текст»** для обычного текстового копирования
- Резервирование и восстановление конфигурации Blizzard Chat
- Защита хорошего резерва от перезаписи явно сброшенной/пустой конфигурацией
- Русская и английская локализация интерфейса
- Команды принудительного переключения языка для тестирования
- Лёгкая архитектура с минимальной дополнительной нагрузкой

## Установка

1. Скачайте `WoW_Chat_v1.0.0.zip` из последнего Release.
2. Распакуйте папку `WoW_Chat` в:
   `World of Warcraft/Interface/AddOns/`
3. При обновлении замените существующую папку `WoW_Chat`; WTF и SavedVariables не удаляйте.
4. Перезапустите клиент игры или выполните `/reload`, если аддон уже был установлен.
5. Откройте настройки командой `/wowchat`.

## Команды

- `/wowchat` — открыть настройки аддона
- `/uwowchat` — старая совместимая команда
- `/wowchat lang ruRU` — принудительно включить русский интерфейс
- `/wowchat lang enUS` — принудительно включить английский интерфейс
- `/wowchat lang auto` — использовать язык игрового клиента

После изменения языка выполните `/reload`.

## Назначение

WoW Chat не является заменой полноценных чат-модификаторов. Его задача — постоянная история, удобное копирование и восстановление конфигурации чата после случайных сбросов.
