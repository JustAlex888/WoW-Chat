# Установка

1. Скачайте `WoW_Chat_v1.0.0.zip` из GitHub Release.
2. Распакуйте папку `WoW_Chat` в `World of Warcraft/Interface/AddOns/`.
3. При обновлении замените существующую папку `WoW_Chat`.
4. Не удаляйте WTF и SavedVariables.
5. Перезапустите клиент или выполните `/reload`.
6. Откройте настройки командой `/wowchat`.
