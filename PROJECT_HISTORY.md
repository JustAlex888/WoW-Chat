# Project History

WoW Chat was created from scratch for a World of Warcraft 7.3.5 client after repeated practical problems with chat history and chat configuration.

The original goals were simple:

- keep chat history across sessions;
- make the history easy to copy;
- preserve familiar chat colors while browsing copied history;
- provide a safety net when Blizzard Chat settings are unexpectedly reset.

The project deliberately stayed focused instead of becoming a large chat replacement.

Created by **JustAlex888** with development assistance from **OpenAI ChatGPT**.
