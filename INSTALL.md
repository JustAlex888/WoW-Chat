# Installation

1. Download `WoW_Chat_v1.0.0.zip` from the GitHub Release.
2. Extract the `WoW_Chat` folder to `World of Warcraft/Interface/AddOns/`.
3. For an update, replace the existing `WoW_Chat` folder.
4. Do not delete WTF or SavedVariables.
5. Restart the client or run `/reload`.
6. Open settings with `/wowchat`.
