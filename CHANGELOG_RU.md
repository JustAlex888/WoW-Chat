# История изменений

## v1.0.0

- Первая стабильная версия для Legion 7.3.5 (Interface 70300).
- Стабилизировано окно копирования длинной истории; оно открывается на новых сообщениях.
- Добавлен индикатор текущего количества сохраняемых строк.
- Улучшена компоновка английского описания резервирования.

## v0.9.1

- Папка аддона переименована в `WoW_Chat`.
- Добавлена полная русская и английская локализация.
- Добавлены команды принудительного переключения языка для тестирования.
- В окно настроек добавлены компактные сведения о версии и разработчике.
- Улучшена работа выделения длинного текста и взаимодействие с окном копирования.
- Автопрокрутка выделения ограничена только ЛКМ и стартом внутри текстовой области.
- Добавлено резервирование и восстановление настроек Blizzard Chat отдельно по персонажам.
- Проект подготовлен к публичному pre-release на GitHub.

## v0.9.0

- Первая полноценная предрелизная тестовая сборка.
- Постоянная история чата.
- Цветное окно копирования.
- Режим «Чистый текст».
- Раздельное хранение истории по персонажам.
- Базовый механизм резервирования настроек Blizzard Chat.
