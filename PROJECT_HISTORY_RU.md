# История проекта

WoW Chat создан с нуля для клиента World of Warcraft 7.3.5 после повторяющихся практических проблем с историей и конфигурацией чата.

Первоначальные задачи были простыми:

- сохранять историю между сессиями;
- удобно копировать сохранённый чат;
- сохранять привычные цвета сообщений при просмотре истории;
- иметь страховку на случай неожиданного сброса настроек Blizzard Chat.

Проект намеренно остался узкоспециализированным и не превращался в тяжёлую полную замену чата.
